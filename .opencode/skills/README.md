# Skills de análise de dados

Skills incluídas neste repositório:

- `explore-data/skill.md`: perfil e exploração da qualidade dos dados.
- `data-visualization/SKILL.md`: escolha, apresentação e acessibilidade de gráficos.
- `Validate-data/SKILL.MD`: revisão de metodologia, cálculos e conclusões.

Os arquivos são mantidos com a grafia original dos diretórios e nomes. Consulte `AGENTS.md` para o fluxo de utilização no projeto.
